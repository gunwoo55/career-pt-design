# 03. UI/UX 설계

## 3.1 디자인 원칙

### 키워드
- **심플 (Simple)**: 불필요한 요소 제거, 직관적인 네비게이션
- **신뢰감 (Trustworthy)**: 프로페셔널한 블루/그린 계열, 깔끔한 타이포그래피
- **동기부여 (Motivating)**: 게이미피케이션, 성취 시각화

### 색상 팔레트
```css
/* Primary Colors */
--color-primary: #3B82F6;        /* 신뢰감 있는 블루 */
--color-primary-dark: #1D4ED8;   /* 딥 블루 */
--color-success: #10B981;        /* 성공/달성 그린 */
--color-warning: #F59E0B;        /* 주의/마감 임박 */
--color-danger: #EF4444;         /* 긴급/마감 */

/* Neutral Colors */
--color-bg: #FFFFFF;             /* 배경 */
--color-bg-secondary: #F8FAFC;   /* 보조 배경 */
--color-text: #1E293B;           /* 본문 */
--color-text-secondary: #64748B; /* 보조 텍스트 */
--color-border: #E2E8F0;         /* 경계선 */

/* Gamification Colors */
--color-gold: #FBBF24;           /* 뱃지/성취 */
--color-purple: #8B5CF6;         /* 특별 보상 */
```

### 타이포그래피
- **Font Family**: 'Pretendard', 'Inter', system-ui
- **Headings**: 700 weight
- **Body**: 400 weight
- **Size Scale**: 12px, 14px, 16px, 18px, 20px, 24px, 32px, 48px

```
[온보딩] → [데일리 대시보드] → [세부 기능]
```

## 3.5 반응형 설계

### 브레이크포인트
| 디바이스 | 너비 | 레이아웃 |
|----------|------|----------|
| 모바일 | 320-767px | 단일 컬럼, 하단 탭바 |
| 태블릿 | 768-1023px | 2컬럼, 사이드바 |
| 데스크톱 | 1024px+ | 3컬럼, 전체 기능 |

### 모바일 최적화
- 터치 타겟 44px 이상
- 하단 고정 네비게이션
- 스와이프 제스처 지원
- 키보드 입력 최적화
