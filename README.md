## 🎯 핵심 기능 (Core Features)

### 1. 🤖 AI 전담 매니저
- **초기 진단 및 로드맵 생성**: 목표 직무, 현재 스펙, 남은 기간 입력 → AI가 합격까지의 로드맵 자동 생성
- **일일 데일리 브리핑**: 매일 아침 오늘 꼭 해야 할 미션 제공
- **습관 형성 (루틴 트래커)**: '매일 알고리즘 1문제', '산업 뉴스 1개 스크랩' 등 루틴 설정 및 달성률 체크
- **스펙 갭(Gap) 분석**: 합격자 평균 데이터와 비교하여 부족한 부분 짚어주기

### 2. 💼 원클릭 포트폴리오 & 이력서 빌더
- **활동 자동 기록**: 앱 내 스크랩, 스터디 이력, 자격증 자동 저장
- **자동 블록 조립**: 저장된 경험들을 선택만 하면 Notion 스타일 또는 PDF로 자동 레이아웃

### 3. 🧠 실전 AI 훈련소
- **AI 자소서 코칭**: 직무 키워드 적합도 검사, 표절률 검사, 소제목 자동 생성
- **AI 모의 면접**: 시선 처리, 목소리 떨림, 필러워드("어, 그, 음") 분석 리포트

### 4. 🫂 커뮤니티 & 멘탈 케어
- **멘탈 케어**: '오늘의 확언', '익명 대나무숲', '소소한 성취 뱃지 시스템'
- **스터디 매칭**: 목표와 현재 상태가 동일한 유저들 매칭

### 5. 📊 통합 정보 허브
- 채용 공고, 인턴십, 대외활동, 부트캠프, 공모전, 자격증 일정 통합 달력
- 마감일 알림
